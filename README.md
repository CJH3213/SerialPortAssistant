# SerialPortAssistant
Qt / SerialPort / BLE(BluetoothLowEnergy) / MCU Communication / PID Balance Vehicle

调参上位机，支持串口、BLE蓝牙的收发通讯，具有字符显示、折线显示和参数调整三界面。
